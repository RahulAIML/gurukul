# ADR-010: Adopt navigation/dashboard-composition patterns from a user-supplied reference; reject its visual treatment

**Status**: Accepted
**Date**: This design phase (mid-phase revision)

## Context
Mid-phase, the user shared an AI-generated reference UI image, explicitly asking for "this kind of UI" while cautioning it was AI-generated and should be elevated by "a proper UI/UX designer," not copied. The reference used: (a) a sidebar+topbar navigation shape with badged Notifications, a streak/points chip, and a bottom-anchored Profile entry; (b) a dashboard composition including a persistent Goals list, a numbered "Your Journey" step sequence, a combined progress-ring+stats card, and a horizontal Popular Programs carousel; (c) a hero visual built entirely from literal mythological/epic artwork (a painted Arjuna-with-bow scene) and ornate temple architecture.

Item (c) directly contradicts this brief's own design-direction guardrail (§3: avoid "overly traditional/religious visual treatment") and the already-selected Hero direction (`UX_ARCHITECTURE.md` §4, "The Guide" — chosen specifically for typographic restraint).

## Decision
Adopt (a) and (b) as genuine navigation/IA improvements — see `INFORMATION_ARCHITECTURE.md` §3 and `UX_ARCHITECTURE.md` §8's Gym Dashboard revision. Explicitly reject (c) — the Hero direction remains "The Guide," unchanged, with no figurative/mythological artwork.

## Consequences
- Sidebar now carries 6 items (5 content destinations + Notifications with badge) instead of 5, with Profile visually separated at the bottom — a real navigation change from the original spec, but confirmed by the user as the correct direction (see `DESIGN_PHASE_REVIEW.md`-style confirmation captured via direct question in this session).
- Gym Dashboard's layout grew a second column (Goals list, Journey timeline) on desktop — an addition to, not a replacement of, the original Today's-Workout-first priority.
- No change to color palette, typography, or hero visual treatment — the parts of the reference in tension with the brief's own guardrails were not adopted.

## Confirmed by
User, via direct confirmation during this design phase (mid-phase question: "Keep it abstract").
