# ADR-007: Dark-mode-only design system

**Status**: Accepted
**Date**: This design phase

## Context
SRS §13's entire palette is dark-only; no light-mode values exist anywhere in the SRS. The new brief didn't ask for light mode but also didn't explicitly rule it out. See `DESIGN_PHASE_REVIEW.md` D6.

## Decision
GURUKUL is dark-mode-only for the foreseeable roadmap (through at least the 8-month plan in `ROADMAP.md`). No theme-switching infrastructure is built.

## Consequences
- Matches the "cinematic imagery," premium-not-SaaS positioning (SRS §1) and avoids doubling design/QA surface area for no current requirement.
- If light mode is ever requested, it requires a full second token set (per `DESIGN_SYSTEM.md` §1's note) and is out of scope for any phase in the current roadmap.
