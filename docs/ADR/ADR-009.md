# ADR-009: `category_coach` role reserved, unused in Gym MVP

**Status**: Accepted
**Date**: This design phase

## Context
SRS §9's RBAC lists `category_coach` alongside `user`, `moderator`, `admin`, but no MVP feature has a defined use case for it (there is no human-coach-in-the-loop feature in Gym MVP scope). See `DESIGN_PHASE_REVIEW.md` D5.

## Decision
The role exists in the RBAC enum (per SRS §9, unchanged) but no permission checks, UI, or endpoints are built around it in this roadmap.

## Consequences
- Prevents building unused permission-check code with no consumer.
- The role becomes relevant once a category introduces human-in-the-loop coaching (not in current scope for any category, including future English/Cricket as currently envisioned) — activating it then is additive, not a rework.
