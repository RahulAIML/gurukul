# ADR-002: Revert visual palette to SRS §13's navy-black, not the drifted neutral-black exploration

**Status**: Accepted
**Date**: This design phase

## Context
SRS §13 specifies `#1a1a2e` (background) / `#16213e` (surface) — a navy-tinted dark palette. An earlier design-canvas pass, done before the full SRS had been read, drifted to a neutral black (`#0f0f0f`/`#1a1a1a`) without flagging the change. See `DESIGN_PHASE_REVIEW.md` Conflict 2.

## Decision
`DESIGN_SYSTEM.md` uses SRS §13's exact values (`#1a1a2e`/`#16213e`/`#A0A0A0`/semantic colors) as the system-of-record. The neutral-black exploration is marked superseded in `docs/design/DESIGN_SYSTEM.md` and not used going forward.

## Consequences
- Any UI already built or mocked against the neutral-black palette must be updated before implementation.
- SRS remains the single source of truth for brand color, avoiding a second silent drift.

## Confirmed by
User, via direct confirmation during this design phase.
